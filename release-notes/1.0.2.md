# Vovis 1.0.2

- 新增演示主播：可在设置中开启或关闭，选择形象，并调整在演示窗口中的位置与大小。
- 提供内置「科技助手」，支持导入小于 100 MB 的本地 VRM 形象；「知性讲师」和「技术讲师」暂时隐藏，待优化后开放。
- 形象预览默认播放讲解动作，可随时暂停或继续。演讲时加入手势与身体转动，全身形象还会适时向左右迈步，停止讲解后自然回位待机。
- 预览支持鼠标上下左右拖动，从不同角度查看完整形象，并可一键恢复默认视角。
- 导入形象时居中显示临时加载进度和当前状态，完成后自动关闭；失败时提示原因，方便重新导入。
- 统一主播设置的卡片、开关和操作按钮样式，改善间距与窄屏布局。
- 支持导出和导入完整的 .vovis 项目包，包含 PDF、讲稿、资料和已有语音，方便换机继续编辑或离线主讲。
- 可提前生成整场语音，支持暂停、继续和失败重试；准备完成后，主讲直接使用已保存的音频。
- 讲稿按页保存，生成超时可重试，也可暂停后从已有进度继续。
- 进入彩排后自动检查内容、语音、音频输出和所选会议，准备就绪即可开始主讲。
- 演讲语言默认中文，也可选择英文；讲稿生成、现场问答与时长估算遵循所选语言。
- 问答阶段不再因空闲 60 秒自动结束，点击「结束演讲」后才会结束并保存记录。
- 改善音频中断后的恢复与重试提示；修复误翻页和页面尚未准备好就开始朗读的问题。
- 主讲准备状态更加清晰，区分页面等待、已保存语音加载和在线语音生成。
- 优化整场语音准备区域的进度、操作与窄屏布局；音色可从列表中选择，也可手动输入 ID。
- 项目按最近使用时间排序，打开项目或查看演讲记录后会更新排序；连续操作时，临时提示只显示最新一条。
- 改善 PDF 中透明图片、字体和色彩的显示；「替换 PDF」入口仅在准备内容阶段展示。
- 启动发现新版时自动展示更新内容，下载时显示进度和已下载大小；检查失败时提示原因并支持重试。
- 改善飞书在企业网络中的连接兼容性，连接失败时提供更明确的提示。
- 恢复 Windows 窗口阴影与 Windows 11 圆角。
