# Vovis 1.0.4

## 主播形象

- 丰富讲解手势，加入身体预备、弧线收回、左右手错峰与手腕跟随；视线先转、头部随后跟随，减少固定姿势反复摆动的感觉。
- 调整眨眼、呼吸与重心变化，全身模型保持双脚落地；内置形象和导入 VRM 共用动作逻辑。
- 修复导入模型的隐藏辅助节点放大动作范围、导致人物显示过小的问题。
- 增加“移除此形象”“切换默认形象”和加载失败后的“重新加载”入口。缺失或损坏的导入模型也能清理，原始 VRM 文件不受影响。

## 语音与演示

- 改善开始讲解时偶发无声的恢复处理，修复切换应用或窗口不可见时，新一页语音等待画面绘制而暂停的问题。
- 修复音频设备重新连接后的演讲录音连续性，保留暂停和恢复的播放位置。

## 导出与更新

- 导出视频时同时保存同名 SRT 字幕，便于剪辑和外部播放器使用。
- 更新日志支持 Markdown 排版，下载进度条采用圆角样式。
- README 增加 CosyVoice2-0.5B 的推荐配置和试听说明。
